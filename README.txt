# Tanuj Web Studio — Demo Website Portfolio

These are static demo websites for showing prospective clients what you can build.

## Demos
1. Jewellery — 01-jewellery-website/index.html
2. Clothing — 02-clothing-website/index.html
3. Mobile Shop — 03-mobile-shop-website/index.html
4. Restaurant — 04-restaurant-website/index.html
5. Local Business — 05-business-website/index.html
6. E-Commerce — 06-ecommerce-website/index.html

## How to use
Open any `index.html` in a browser to preview it. For a client, replace the demo business name, photos, text, phone/WhatsApp number, email, logo, products and links before publishing.

These are portfolio/demo templates, not completed client websites.
